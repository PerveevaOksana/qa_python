# Проект qa_python — тестирование BooksCollector
### Реализованные тесты

Тестирование класса `BooksCollector` покрывает все основные методы:

- `add_new_book`: проверка допустимой длины названия (до 40 символов), запрет пустых строк и дубликатов.
- `set_book_genre`: установка жанра только для существующих книг и только из разрешённого списка жанров.
- `get_book_genre`: корректный возврат жанра или `None` для отсутствующей книги.
- `get_books_with_specific_genre`: фильтрация книг по жанру.
- `get_books_genre`: возврат полного словаря книг.
- `get_books_for_children`: книги с возрастным рейтингом (Ужасы, Детективы) не попадают в список для детей.
- `add_book_in_favorites`: добавление в избранное только книг из коллекции, запрет дубликатов в избранном.
- `delete_book_from_favorites`: удаление из избранного и безопасное поведение при отсутствии книги.

## Особенности реализации

- Каждый тест содержит ровно один `assert`.
- Использована параметризация для сценариев с разными входными данными.
- Нет условий (`if/else`) в теле проверок.
